# 常见问题 / FAQ

## 安装与运行

### Word 提示“宏已被禁用”，快捷键没反应

在 `文件` → `选项` → `信任中心` → `信任中心设置` → `宏设置` 中允许宏运行，或把文档/模板放到受信任位置。公司电脑可能由组策略管理，请联系管理员。不要为了这个宏盲目关闭所有安全设置。

### 宏列表里找不到 `CaretDownAlignedFinal`

1. 确认代码粘贴/导入到了正确工程（`Normal` 或当前文档）。
2. 在 VBA 编辑器执行 `调试` → `编译 VBAProject` 看是否有编译错误。
3. 在 `文件` → `选项` → `自定义功能区` → `键盘快捷方式：自定义…` 里，类别选择“宏”再查找。
4. 如果 Word 只显示部分宏，检查“宏的位置”下拉框。

### 快捷键 `Alt + ↓` 被占用

换一个组合，例如 `Ctrl + Alt + ↓` 或 `Alt + J`。务必确认对话框里“当前指定到”没有冲突。

### 安装后出现两个同名宏

说明旧模块没删干净。打开 VBA 编辑器，删除所有旧的 `CaretDownAligned` / `CaretDownAlignedFinal` 过程或模块，只保留一份新代码，再重新绑定快捷键。

## 已知错误

### 438「方法和数据成员未找到」

1.0 之前的版本使用了 `Paragraph.Index`。Word 的 `Paragraph` 对象没有 `Index` 属性，所以运行到“找下一段”时会报 438。1.0 已改为遍历 `Paragraphs` 集合，用 `Range.Start` 定位当前段。

如果 1.0 仍报 438：

- 确认旧模块已全部删除，没有残留的旧 `CaretDownAlignedFinal`；
- 确认模块名不叫 `CaretDownAlignedFinal`（模块名和宏名不要相同）；
- 确认代码粘贴完整，没有少 `End Sub` / `End Function`；
- 检查 VBA `工具` → `引用` 是否有 `MISSING` 项；
- 如果使用 WPS，注意其 Word 兼容对象模型可能与 Microsoft Word 不同，本项目未正式支持 WPS。

### 4608「数值超出范围」

旧版在文档末尾用 `InsertAfter` 插入段落，触发 4608。1.0 改用 `Paragraph.Range.InsertParagraphAfter`，并把光标移入新段落。请更新到 1.0，不要保留旧代码。

### 运行后光标还是没落到词下面

按顺序检查：

1. 目标行是不是 **1.0 生成的网格行**？旧版“首行缩进”行没有左侧列，必须删除重建。
2. 是不是从**日文行**按的快捷键？从注释行按会跳到下一段。
3. 目标词是不是在注释行已有文字的**左侧**？网格行可以处理，但必须已生成网格；旧行不行。
4. 目标词是否靠近右边界，超出了网格最后一列？接近页边距时只能落在最近的字符边界。
5. 文档是否在表格、文本框、分栏或竖排中？这些场景不支持。
6. 注释行是否被手动删掉了全角空格？那样它不再被识别为网格行。

## 对齐与排版

### 为什么不直接按 ↓ 或“回车”？

- 普通 `↓` 在空白行只能落到段落起点，不能落在任意列。
- 在光标处按回车会拆分段落，把「が話しています。」挤到下一行。本宏故意不这么做。

### 为什么注释行里有很多全角空格？

Word 的普通文本行没有“虚拟列”。要让光标停在某个水平位置，必须有一个可停靠的字符或格式锚点。全角空格（`U+3000`）正好是一个全角字符的宽度，因此用它们铺一条字符网格。关闭“显示编辑标记”时它们通常不可见。

### 为什么自动变成“改写”模式？

在同一行补写左边的词时，普通“插入”模式会把后面的注释向右推。改写模式让新输入的字符替换空格，保持后面的注释位置不变。状态栏会显示“改写”；写完按 `Insert` 切回插入模式。

### 我不想用改写模式，怎么办？

可以只用插入模式从**左往右**写注释：先注释最左边的词，再依次向右，插入的文字会进入右侧空格区，不会影响左边已写好的注释。若必须任意顺序补写，改写模式或表格更合适。

### 半角英文/数字为什么会偏？

一个全角空格宽 `1em`，一个半角字符通常只有 `0.5em` 左右。改写模式按“一个字符替换一个空格”工作，半角字符会留下半个空格的偏差，后面的文字可能移动半列。要精确对齐，注释尽量使用全角中文/日文。

### 改注释行的字号后为什么失准？

网格列宽是按源文字字号生成的（全角空格 = 1em）。把注释行字号改大或改小，列宽就变了。要改字号，请重新生成注释行，或统一源文字和注释的字号。

### 可以放在表格里用吗？

不可以。宏检测到当前选择在表格内会直接退出。表格本身是更稳定的按词/按字符对齐方案：可以建立两行表格（日文一行、注释一行），每个词或字符一列，不需要空格网格和改写模式。

### 能在分栏、文本框、竖排里用吗？

不支持。分栏宽度、文本框和竖排的坐标语义不同，宏会拒绝执行（文本框/非正文故事会被 `StoryType` 检查挡住）。

### 支持 WPS / Word for Mac 吗？

未正式测试。宏使用 Microsoft Word 的 VBA 对象模型；WPS 的兼容层可能缺少部分成员，Word for Mac 的坐标/界面也可能不同。若在这些环境使用，请先备份并自行测试，或改用表格方案。

## 清理与撤销

### 怎么删除注释行？

选中整条注释行（包括段落标记）删除即可。日文句子不受影响。网格里的全角空格会随行一起删除。

### 怎么撤销一次对齐？

按 `Ctrl + Z`。宏的段落格式修改和插入的空格通常可以撤销；如果撤销不完整，手动删除注释行并重新生成。

### 更新宏后旧注释行还能用吗？

1.0 之前用首行缩进生成的行不能用；1.0 生成的网格行可以继续用。旧行会触发删除提示。

### 宏会修改我的日文原文吗？

不会主动修改原句文字。它只读取光标位置，在日文段落之后创建/定位注释段落。但宏会修改段落格式、插入全角空格、切换改写模式；使用前请备份，写完注释后注意切回插入模式。

## 版本与反馈

### 如何确认版本？

查看仓库根目录的 [`VERSION`](../VERSION) 或 Release 标签；当前为 `1.0.0`。

### 如何报告问题？

使用 GitHub Issue 模板，提供 Word 版本、Windows 版本、宏版本、操作步骤、错误号和 VBA 高亮行。不要上传真实学习笔记或个人文档；用最小化的示例。安全问题请按 [SECURITY.md](../SECURITY.md) 私密报告。
