# 安装与卸载 / Installation

本文以 Windows 版 Microsoft Word 为例。界面名称可能因 Word 版本和语言略有不同。

## 0. 开始之前

1. **备份文档**。宏会插入全角空格、修改段落格式并切换改写模式。
2. 备份 `Normal.dotm`（如果要把宏装到全局模板）。路径通常为：

   ```text
   %APPDATA%\Microsoft\Templates\Normal.dotm
   ```

3. 关闭不需要的 Word 文档，避免快捷键或宏列表冲突。
4. 确认 Word 允许运行宏。公司电脑可能有组策略限制，需联系管理员。

> 正常手动安装**不需要**打开“信任对 VBA 工程对象模型的访问”。本宏不使用 `VBProject` 自动化。

## 1. 安装

### 方案 A：导入英文 `.bas`

1. 下载 [`../src/CaretDownAligned.bas`](../src/CaretDownAligned.bas)。
2. 在 Word 中按 `Alt + F11`。
3. 在 VBA 编辑器里选择 `文件` → `导入文件…`（File → Import File）。
4. 选择 `CaretDownAligned.bas`。
5. 左侧工程窗口会出现 `CaretDownAlignedModule`。
6. 菜单 `调试` → `编译 VBAProject`（Debug → Compile VBAProject）。
7. 如果没有报错，关闭 VBA 编辑器。

英文 `.bas` 的用户提示是英文；逻辑与中文版相同。

### 方案 B：复制中文代码

1. 打开 [`../src/CaretDownAligned.zh-CN.vba.txt`](../src/CaretDownAligned.zh-CN.vba.txt)。
2. 在 Word 中按 `Alt + F11`。
3. 左侧工程窗口右键 `Normal` 或当前文档 → `插入` → `模块`。
4. 如果新模块顶部已经有 `Option Explicit`，保留它。
5. 从中文文件的注释标题行开始，全选复制，粘贴到模块中。
6. `调试` → `编译 VBAProject`。
7. 关闭 VBA 编辑器。

> 不要把 `.zh-CN.vba.txt` 的说明文字当成代码粘贴；从第一行注释开始即可，注释不影响运行。文件里没有 `Attribute VB_Name` 行，这是为了复制粘贴安全。

### 安装到哪个工程？

- 希望**所有文档**都能用：安装到 `Normal.dotm`（Normal 工程）。
- 只希望**当前文档**能用：安装到当前文档的工程，并把文档保存为 `.docm`。

## 2. 绑定快捷键

1. `文件` → `选项` → `自定义功能区`。
2. 底部点击 `键盘快捷方式：自定义…`。
3. 在“类别”中选择「宏」。
4. 在右侧找到 `CaretDownAlignedFinal` 并选中。
5. 光标放到“请按新快捷键”，按下 `Alt + 下方向键`。
6. 点击 `指定`。
7. “将更改保存在”：
   - `Normal.dotm`：全局可用；
   - 当前文档：仅此文档可用。
8. 关闭对话框。如果 Word 提示保存模板，选择保存。

如果 `Alt + ↓` 已被其他命令占用或不起作用，改用 `Ctrl + Alt + ↓`、`Alt + J` 等组合，并在 Word 中确认“当前指定到”没有冲突。

## 3. 首次测试

1. 新建一个空白文档。
2. 输入：

   ```text
   先生と学生が話しています。
   ```

3. 回车，让第二行成为空段落。
4. 回到第一行，把光标放在「学生」后面。
5. 按 `Alt + ↓`。
6. 光标应出现在第二行与「学生」相同的水平位置；第一行文字不应移动。
7. 输入「学生」。
8. 回到第一行，把光标放在「先生」后面，再按 `Alt + ↓`。
9. 光标应回到同一注释行的「先生」列，状态栏可能显示“改写”。
10. 输入「老师」，确认「学生」没有被推走。
11. 按 `Insert` 切回插入模式。

## 4. 从旧版本升级

1. 打开 VBA 编辑器。
2. 删除所有包含旧 `CaretDownAligned` / `CaretDownAlignedFinal` 的模块，避免同名过程和 438。
3. 按方案 A 或 B 重新安装。
4. 回到文档，删除旧版用“首行缩进”生成的注释行（文字先复制）。
5. 从日文行重新按 `Alt + ↓` 生成网格注释行，再粘贴/输入注释。
6. 如果快捷键仍指向旧宏，重新在键盘快捷方式对话框中指定 `CaretDownAlignedFinal`。

旧版注释行会触发提示：

> 检测到旧版生成的缩进注释行。请先删除这一行，再回到日文行重新按 Alt+↓ 生成新的网格注释行。

## 5. 卸载

1. 打开 `Alt + F11`。
2. 删除 `CaretDownAlignedModule` 模块（或你粘贴代码的模块）。如果模块里还有其他宏，只删除本项目的宏和辅助函数。
3. 在 `文件` → `选项` → `自定义功能区` → `键盘快捷方式：自定义…` 中删除 `Alt + ↓` 的绑定。
4. 保存 `Normal.dotm`。
5. 文档中已有的全角空格注释行不会被自动删除；需要时手动删除对应注释行。

## 6. 宏安全与文件解锁

- Word 可能会阻止来自 Internet 的宏。打开文档后若顶部出现安全警告，确认来源可信后再启用。
- 如果文件属性里有“解除锁定”（Unblock），可在文件资源管理器中右键文件 → `属性` → 勾选“解除锁定” → 确定。
- 不要为了本宏把 Word 设置为“启用所有宏”而不加判断；请遵循公司安全策略。
- 本宏没有网络请求、没有文件写入、没有外部程序调用，源码可审计。

## 7. 常见安装问题

**宏列表里找不到 `CaretDownAlignedFinal`**

- 代码是否粘贴到了正确工程/模块；
- 是否执行了 `调试` → `编译 VBAProject`；
- 宏是否被 Word 的宏安全设置禁用；
- 当前“宏的位置”是否选对了（Normal.dotm 还是当前文档）。

**绑定快捷键后没反应**

- 检查快捷键是否被其他命令占用；
- 是否把更改保存在了当前文档，但换了一个文档测试；
- 是否有两个同名宏，快捷键指向了被删除/旧的那个；
- 是否在表格、文本框或分栏中按了快捷键（宏会 Beep 并退出）。

**438 / 4608**

见 [FAQ.md](FAQ.md)。1.0 已修复这两个已知错误；若仍出现，通常是旧代码未删除干净或环境不兼容。
